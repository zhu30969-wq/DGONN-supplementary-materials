## Contents

The supplement contains Sections S1–S10, Figures S1–S5, Tables S1–S29, and 14 references:

1. Modeling assumptions and data protocol
2. Certificate implementation and audit
3. Block size
4. Relaxation hierarchy and readout diagnostics
5. Extended target families and amplitude encoding
6. Zeroth-order training and resource accounting
7. Fine-tuning on simulated chips
8. Optical power and offline robustness
9. DGONN reconstruction and comparison
10. Internally pre-specified tests, gates and interpretation rules

This repository distributes the supplemental document. Simulation records, trained networks, teacher feature caches, certificate verification witnesses, and analysis code are described by the manuscript's data availability statement and are not included in this repository.
